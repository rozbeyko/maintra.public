Icons

Cut from the same sheet as the rest of Maintra: straight lines, octagons, square ends. 69 marks in total, split into controls and things. If a screen needs one that is not here, draw it with the same rules before reaching for a library.

Cut, not roundedSquare ends, sharp joins, 45° chamfers where a set would round a corner. Same cut as our cards and buttons.
Round only if it is roundWheels, discs, gauges and lenses of real things stay circles. Everything else is straight lines and octagons.
One weight, one colour1.8 at 20–24 px, 2.2 at 14–16 px. Text colour or muted. Gold only on the one thing you can press. No coloured tiles behind icons.
Only where it earns itThings: service history, spending by category, the + menu, places. Actions: toolbars and controls. Never next to a label that already says it: no calendar by “Date”, no cog by “Settings”.
